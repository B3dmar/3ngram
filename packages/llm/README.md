# @3ngram/llm

Embedding gateway and metered-operation registry for 3ngram. It includes an
OpenAI-compatible embedding client and a deterministic fake gateway for tests.
Text generation is intentionally not implemented in v1.

This is a low-level runtime package. See the
[3ngram repository](https://github.com/B3dmar/3ngram) for configuration,
privacy, and self-hosting guidance.
