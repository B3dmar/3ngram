# @3ngram/schema

The shared Zod validation boundary for 3ngram. MCP, REST, the SDK, core
services, and database constraints derive their public shapes and enums from
this package.

See the [3ngram repository](https://github.com/B3dmar/3ngram) for the API and
data-model documentation.
