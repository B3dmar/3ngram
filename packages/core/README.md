# @3ngram/core

Transport-independent domain services for 3ngram: typed memory writes and
reads, search, scopes, commitments, import/export, account lifecycle, budget
enforcement, and proposal workflows.

This is a low-level composition package. Applications should usually use the
MCP server, REST API, CLI, or `@3ngram/sdk`. See the
[3ngram repository](https://github.com/B3dmar/3ngram) for architecture and
self-hosting documentation.
